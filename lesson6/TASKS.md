# Задачи: Введение в объектно-ориентированное программирование (ООП)

**Уровень:** Beginner / Easy  
**Темы:** Классы, объекты, конструктор `__init__`, методы, наследование, инкапсуляция, полиморфизм, абстракция, композиция

---

## Задача 1. Класс «Студент» (базовый)

**Цель:** Создать простой класс и несколько объектов.

1. Создайте класс `Student` с атрибутами: `name` (имя), `age` (возраст), `grade` (оценка).
2. Добавьте конструктор `__init__`, который принимает эти три параметра.
3. Добавьте метод `info()`, который возвращает строку вида: `"Имя: ..., Возраст: ..., Оценка: ..."`.
4. Создайте 2–3 объекта `Student` и выведите информацию о каждом через `info()`.

**Пример вывода:**
```
Имя: Алиса, Возраст: 20, Оценка: 85
Имя: Боб, Возраст: 22, Оценка: 78
```

## Задача 2. Класс «Прямоугольник»

**Цель:** Работа с атрибутами и методами, возвращающими значения.

1. Создайте класс `Rectangle` с атрибутами `width` (ширина) и `height` (высота).
2. Добавьте метод `area()`, который возвращает площадь прямоугольника.
3. Добавьте метод `perimeter()`, который возвращает периметр.
4. Создайте прямоугольник 5×3 и выведите его площадь и периметр.

**Пример вывода:**
```
Площадь: 15
Периметр: 16
```

## Задача 3. Класс «Счётчик»

**Цель:** Методы, изменяющие состояние объекта.

1. Создайте класс `Counter` с атрибутом `value` (начальное значение 0).
2. Добавьте метод `increment()` — увеличивает `value` на 1.
3. Добавьте метод `decrement()` — уменьшает `value` на 1.
4. Добавьте метод `reset()` — сбрасывает `value` в 0.
5. Создайте счётчик, вызовите `increment()` 3 раза, затем `decrement()` 1 раз и выведите итоговое значение.

**Пример вывода:**
```
Текущее значение: 2
```

## Задача 4. Класс «Книга»

**Цель:** Инкапсуляция и метод с параметрами.

1. Создайте класс `Book` с атрибутами: `title` (название), `author` (автор), `pages` (количество страниц).
2. Добавьте метод `read(pages_read)`, который уменьшает `pages` на прочитанное количество (но не меньше 0).
3. Добавьте метод `is_finished()`, который возвращает `True`, если `pages == 0`, иначе `False`.
4. Создайте книгу на 100 страниц, «прочитайте» 30, затем 70 страниц и проверьте, закончена ли книга.

## Задача 6. Наследование: «Фигуры»

**Цель:** Наследование с общим методом.

1. Создайте базовый класс `Shape` с методом `area()`, возвращающим 0.
2. Создайте класс `Circle`, наследующий `Shape`, с атрибутом `radius`. Переопределите `area()` — формула: `3.14 * radius ** 2`.
3. Создайте класс `Square`, наследующий `Shape`, с атрибутом `side`. Переопределите `area()` — формула: `side ** 2`.
4. Создайте круг с радиусом 5 и квадрат со стороной 4. Выведите площади обеих фигур.

**Пример вывода:**
```
Площадь круга: 78.5
Площадь квадрата: 16
```

## Задача 7. Список студентов (комплексная, лёгкая)

**Цель:** Объединение классов и списков.

1. Используйте класс `Student` из Задачи 1.
2. Создайте класс `StudentList` с атрибутом `students` (список объектов `Student`).
3. Добавьте метод `add(student)` — добавляет студента в список.
4. Добавьте метод `average_grade()` — возвращает среднюю оценку всех студентов.
5. Добавьте метод `best_student()` — возвращает студента с максимальной оценкой (или `None`, если список пуст).
6. Создайте `StudentList`, добавьте 3 студентов и выведите среднюю оценку и лучшего студента.

## Задача 8. Инкапсуляция: «Банковский счёт»

**Цель:** Скрытие данных через приватные атрибуты и методы доступа.

1. Создайте класс `BankAccount` с приватным атрибутом `_balance` (баланс). Конструктор принимает начальный баланс.
2. Добавьте метод `deposit(amount)` — пополнение счёта.
3. Добавьте метод `withdraw(amount)` — снятие денег (не допускайте отрицательный баланс).
4. Добавьте метод `get_balance()` — возвращает текущий баланс (единственный способ узнать баланс снаружи).
5. Создайте счёт с 1000, пополните на 500, снимите 300 и выведите баланс.

**Подсказка:** Используйте `self._balance` (один underscore — соглашение о «приватности» в Python).

## Задача 9. Абстракция: «Транспорт»

**Цель:** Абстрактный базовый класс (ABC) и обязательная реализация методов.

1. Импортируйте: `from abc import ABC, abstractmethod`
2. Создайте абстрактный класс `Vehicle(ABC)` с абстрактным методом `start_engine()`.
3. Создайте класс `Car`, наследующий `Vehicle`. Реализуйте `start_engine()` — возвращает `"Двигатель машины заведён"`.
4. Создайте класс `Bicycle`, наследующий `Vehicle`. Реализуйте `start_engine()` — возвращает `"У велосипеда нет двигателя"`.
5. Создайте объекты `Car` и `Bicycle` и вызовите `start_engine()` для каждого.

**Подсказка:** `@abstractmethod` не позволяет создать объект абстрактного класса — только наследников.

## Задача 10. Композиция: «Библиотека и книги»

**Цель:** Связь «имеет» (has-a) — объект содержит другие объекты.

1. Используйте класс `Book` из Задачи 4 (или создайте упрощённый: `title`, `author`).
2. Создайте класс `Library` с атрибутом `books` (список книг). Конструктор инициализирует пустой список.
3. Добавьте метод `add_book(book)` — добавляет книгу в библиотеку.
4. Добавьте метод `find_by_author(author)` — возвращает список книг данного автора.
5. Добавьте метод `total_books()` — возвращает количество книг.
6. Создайте библиотеку, добавьте 3–4 книги (в т.ч. 2 от одного автора), найдите книги по автору и выведите общее количество.

**Подсказка:** Композиция — когда `Library` «имеет» список `Book`, а не наследует от него.

## Подсказки

- Конструктор: `def __init__(self, param1, param2): self.param1 = param1`
- Наследование: `class Dog(Animal):`
- Вызов метода родителя: `super().method_name()`
- Проверка на пустой список: `if not self.students: return None`
- Приватный атрибут: `self._balance` (соглашение, не строгая защита)
- Абстракция: `from abc import ABC, abstractmethod`; `class Vehicle(ABC):`; `@abstractmethod` над методом
- Композиция vs наследование: «имеет» (Library has books) — композиция; «является» (Car is Vehicle) — наследование

## Задача 1. Рефакторинг в класс (mid)

**Цель:** Превратить процедурный код в ООП.

1. Создайте класс `StudentDataProcessor` в `lesson6/`:
   - конструктор принимает путь к `students.json` (по умолчанию — путь относительно вашего проекта);
   - метод `load()` — загружает JSON и возвращает список;
   - метод `filter_young(age_threshold)` — возвращает имена студентов младше порога (порог по умолчанию уточните у преподавателя, если не указан в задании);

   - метод `save_filtered(output_path, **filters)` — сохраняет результат в JSON по переданным фильтрам.
2. **Пояснение (3–5 предложений):** Почему вы выбрали именно такую сигнатуру `save_filtered`? Что бы изменили, если бы фильтров было 10?

## Задача 2. Кэширующий загрузчик (mid)

**Цель:** Инкапсуляция и управление состоянием.

1. Создайте класс `CachedJsonLoader`:
   - конструктор принимает путь к JSON-файлу;
   - метод `get_data()` — при первом вызове читает файл и сохраняет в приватный атрибут, при последующих возвращает кэш;
   - **запрещено** использовать глобальные переменные и `@staticmethod` для хранения кэша.
2. Реализуйте метод `invalidate()` — сбрасывает кэш (следующий `get_data()` снова читает файл).
3. Используйте загрузчик для `products.json`. Вызовите `get_data()` дважды, затем `invalidate()`, затем снова `get_data()`.
4.  В выводе должно быть видно, что вы как-то отличили «чтение из файла» от «чтение из кэша» (например, print при первом чтении).

## Задача 3. Иерархия для продуктов (mid+)

**Цель:** Наследование и полиморфизм на реальных данных.

1. Загрузите `products.json`. Товары имеют поля: `id`, `name`, `category`, `price`, `tags`.
2. Создайте абстрактный класс `Product` (ABC) с абстрактным методом `get_display_info()` → строка для вывода.
3. Создайте класс `ElectronicsProduct(Product)` — для `category == "Electronics"`. В `get_display_info()` включите цену в тенге и пометку «Электроника».
4. Создайте класс `FurnitureProduct(Product)` — для `category == "Furniture"`. В `get_display_info()` включите цену и пометку «Мебель».
5. Создайте фабричную функцию `product_from_dict(d: dict) -> Product`, которая по `category` возвращает нужный подкласс.
6. **Обработайте случай:** если `category` не "Electronics" и не "Furniture", верните объект базового класса `GenericProduct` с реализацией `get_display_info()`.
7. Выведите `get_display_info()` для всех товаров из `products.json`.

**Вопрос для размышления (письменно, 2–3 предложения):** Зачем нужен `GenericProduct`? Что произойдёт, если его не создать и прийти неизвестная категория?

## Задача 4. Композиция: Агрегатор отчётов (mid+)

**Цель:** Композиция, один объект управляет несколькими источниками.

1. Создайте класс `ReportSource` (ABC) с абстрактным методом `fetch() -> list[dict]`.
2. Реализуйте `JsonReportSource(ReportSource)` — читает `students.json`, возвращает список словарей.
3. Реализуйте `XlsxReportSource(ReportSource)` — читает `sales.xlsx`, возвращает список словарей (каждая строка — dict).
4. Создайте класс `ReportAggregator`:
   - конструктор принимает список `ReportSource` (композиция: агрегатор «имеет» источники);
   - метод `merge_all() -> list[dict]` — объединяет результаты всех источников (просто конкатенация списков);
   - метод `total_records() -> int` — общее количество записей.
5. Создайте агрегатор с `JsonReportSource` для students и `XlsxReportSource` для sales. Вызовите `merge_all()` и `total_records()`.
6. **Скриншот:** Вывод `total_records()` и первые 2 записи из `merge_all()` с вашим именем в первой строке.

## Задача 6. Интеграция с вашим кодом (mid+)

**Цель:** Работа с существующей кодовой базой.

1. Найдите в проекте класс `JsonLinesIterator` (lesson4). Изучите его интерфейс.
2. Создайте класс `JsonLinesProcessor`, который **использует** `JsonLinesIterator` (композиция) и добавляет:
   - метод `to_list()` — возвращает все записи в виде списка;
   - метод `count_by_key(key)` — возвращает `Counter` (или dict) с подсчётом значений по указанному ключу в каждой записи.
3. Протестируйте на `logs.jsonl`. Если в `logs.jsonl` нет подходящего ключа — временно добавьте в файл 2–3 записи с полем `"level": "info"` или `"type": "A"` и используйте его.
4. **Скриншот:** Вывод `count_by_key` с вашим именем в первой строке.

**Критерий проверки:** Ваш `JsonLinesProcessor` должен импортировать `JsonLinesIterator` из вашего `lesson4` (или откуда он у вас находится). Путь импорта должен соответствовать структуре проекта.

## Задача 1. List comprehension (лёгкая, 15 баллов)

Дан список студентов:
```python
students = [
    {"name": "Алиса", "age": 20, "grade": 85},
    {"name": "Боб", "age": 22, "grade": 72},
    {"name": "Виктор", "age": 19, "grade": 90},
]
```

Напишите **list comprehension**, который создаёт список имён студентов с оценкой **выше 80**.  
Выведите результат.

## Задача 4. Итератор (средняя, 25 баллов)

Реализуйте класс `CountDown` — итератор, который при переборе в цикле `for` выдаёт числа от `n` до 1 (включительно), затем останавливается.

Требования:
- конструктор принимает `n`;
- реализуйте `__iter__` и `__next__`;
- при достижении конца — `StopIteration`.

Пример: `for x in CountDown(3): print(x)` → выводит 3, 2, 1.

## Задача 5. Класс + comprehensions (средняя, 30 баллов)

Дан список продаж:
```python
sales = [
    {"product": "A", "qty": 5, "price": 100},
    {"product": "B", "qty": 12, "price": 50},
    {"product": "A", "qty": 3, "price": 100},
]
```

Создайте класс `SalesReport`:
- конструктор принимает список `sales`;
- метод `big_orders(min_qty)` — возвращает список продаж с `qty >= min_qty` (через **list comprehension**);
- метод `total_by_product()` — возвращает словарь `{product: сумма (qty * price) по всем записям}`.

Создайте объект, вызовите `big_orders(5)` и `total_by_product()`, выведите результаты.

## Задача 1. Dict comprehension (лёгкая, 15 баллов)

Дан список товаров:
```python
products = [
    {"name": "Телефон", "price": 50000, "category": "Электроника"},
    {"name": "Стул", "price": 15000, "category": "Мебель"},
    {"name": "Ноутбук", "price": 250000, "category": "Электроника"},
]
```

Напишите **dict comprehension**, который создаёт словарь `{name: price}` только для товаров категории **«Электроника»**.  
Выведите результат.

## Задача 2. Класс «Счётчик» (лёгкая, 15 баллов)

Создайте класс `Counter`:
- атрибут `value` (начальное значение 0 в конструкторе);
- метод `increment()` — увеличивает `value` на 1;
- метод `decrement()` — уменьшает `value` на 1;
- метод `reset()` — сбрасывает в 0.

Создайте счётчик, вызовите `increment()` 3 раза, `decrement()` 1 раз, выведите итоговое значение.

## Задача 4. Генератор (средняя, 25 баллов)

Напишите **генератор** `count_up_to(n)`, который при переборе в цикле `for` выдаёт числа от 0 до `n-1` (включительно), затем останавливается.

Требования:
- используйте `yield`;
- не создавайте список в памяти.

Пример: `for x in count_up_to(4): print(x)` → выводит 0, 1, 2, 3.

## Задача 5. Класс + JSON (средняя, 30 баллов)

Дан список студентов (можно считать, что он уже загружен из JSON):
```python
students = [
    {"name": "Иван", "age": 20, "grade": 88, "city": "Алматы"},
    {"name": "Мария", "age": 21, "grade": 75, "city": "Астана"},
    {"name": "Пётр", "age": 19, "grade": 92, "city": "Алматы"},
]
```

Создайте класс `StudentFilter`:
- конструктор принимает список `students`;
- метод `top_students(threshold)` — возвращает список имён с оценкой **не ниже** `threshold` (через **list comprehension**);
- метод `by_city(city)` — возвращает словарь `{name: grade}` для указанного города (через **dict comprehension**).

Создайте объект, вызовите `top_students(80)` и `by_city("Алматы")`, выведите результаты.  
*Дополнительно:* напишите, как сохранить результат в JSON-файл (одна строка с `json.dump`).

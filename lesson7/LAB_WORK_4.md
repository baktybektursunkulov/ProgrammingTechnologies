# Лабораторная работа: NumPy и объектно-ориентированное программирование

## Цель работы
Научиться совмещать работу с массивами `numpy.ndarray` с проектированием классов: инкапсулировать данные и операции в методах, применять наследование и полиморфизм для сменяемых алгоритмов, собирать решение из нескольких объектов (композиция).

## Задание 1. Класс «Вектор»

**Цель:** инкапсулировать одномерный массив и операции над ним в одном классе (как данные и методы собраны в одном месте).

1. Создайте класс `NVector` — обёртка над **одномерным** массивом NumPy.
2. **Конструктор** принимает итерируемое чисел или `np.ndarray`. Внутри сохраните `np.ndarray` типа `float64` формы `(n,)`. Если после приведения размерность не одномерная — выбросьте `ValueError`.
3. Реализуйте интерфейс класса:
   - свойство **`values`** — возвращает **копию** внутреннего массива (`copy()`), чтобы снаружи нельзя было испортить данные, не используя методы класса;
   - **`__len__`** — число компонент;
   - **`dot(other)`** — скалярное произведение с другим `NVector`; если длины разные — `ValueError`;
   - **`norm()`** — евклидова норма (например, `np.linalg.norm`);
   - **`__add__(other)`** — поэлементное сложение двух `NVector` одинаковой длины, иначе `ValueError`;
   - **`__repr__`** — понятная строка (например, размерность и первые элементы или полный список при малом `n`).

**Демонстрация:** создайте два вектора, выведите их сумму, скалярное произведение и нормы каждого (одной-двумя строками `print`).

## Задание 2. Класс «Матрица наблюдений»

**Цель:** хранить таблицу чисел в одном объекте и считать статистики по строкам/столбцам через `axis`, не размазывая код по файлу.

1. Создайте класс `ObservationMatrix` для двумерных данных (строки — наблюдения, столбцы — признаки).
2. **Конструктор** принимает `np.ndarray` формы `(n, m)` или вложенный список списков; сохраните внутри как `float64`.
3. Добавьте удобный доступ к размеру (свойства или методы): **`shape`**, **`n_rows`**, **`n_cols`** (или эквивалентно одно свойство `shape` и вычисление числа строк/столбцов).
4. Реализуйте методы:
   - **`column_means()`** — одномерный массив длины `m`: среднее по **каждому столбцу** (`axis=0`);
   - **`row_sums()`** — одномерный массив длины `n`: сумма по **каждой строке** (`axis=1`);
   - **`standardize_columns()`** — возвращает **новый** объект `ObservationMatrix`: по каждому столбцу z-score (среднее 0, стандартное отклонение 1, `ddof=0`). Исходный объект **не** изменять.

**Демонстрация:** постройте матрицу минимум `4×3` (например, `np.arange(12).reshape(4, 3)` или случайные числа). Выведите столбцовые средние исходной матрицы; затем создайте стандартизованную версию и выведите её столбцовые средние и `std` (должны быть около 0 и 1).

## Задание 3. Наследование: преобразования массива

**Цель:** полиморфизм — разные классы, один интерфейс.

1. Создайте абстрактный базовый класс `ArrayTransform` (`abc.ABC`) с абстрактным методом `apply(self, arr: np.ndarray) -> np.ndarray`.
2. Реализуйте **не менее двух** подклассов, например:
   - `ClipTransform` — в конструкторе `min_v`, `max_v`, в `apply` вызывает `np.clip`;
   - `ScaleTransform` — умножает все элементы на константу `factor`.
3. Запрещено дублировать проверку типа входа в каждом подклассе полностью: общую проверку «`arr` — ndarray» можно вынести в приватный метод базового класса или в `apply` базового шаблона (на усмотрение, главное — не копировать десять строк в каждом наследнике без причины).

**Демонстрация:** один массив пропустите через два разных преобразования по очереди, выведите фрагменты до/после.

## Задание 4. Композиция: конвейер преобразований

## Задание 5 (Middle+). Матрица квадратов расстояний между строками

**Цель:** научиться считать попарные квадраты расстояний между всеми строками матрицы **одной векторизованной формулой** (без двойного цикла по парам) и спрятать это в класс.

1. Создайте класс `SquaredDistanceMatrix` (или согласуйте имя с преподавателем). Он представляет набор из `P` точек в `k`-мерном пространстве: строка матрицы — координаты одной точки.
2. **Конструктор** принимает `np.ndarray` формы `(P, k)`. Если массив не двумерный — `ValueError`. Сохраните данные как `float64`.
3. Реализуйте **`points`** (свойство или метод без аргументов) — возвращает **копию** матрицы точек, чтобы извне нельзя было случайно испортить `X`.
4. Реализуйте **`as_matrix() -> np.ndarray`** — матрица `D2` размера `(P, P)`, где  
   `D2[i, j] = ‖X[i] − X[j]‖²` (квадрат евклидова расстояния).  
   Запрещено заполнять `D2` вложенными циклами `for i` / `for j` по всем парам. Используйте тождество  
   `‖a − b‖² = ‖a‖² + ‖b‖² − 2(a·b)`  
   для строк матрицы `X`: сначала `r = (X ** 2).sum(axis=1)` (вектор длины `P`), затем  
   `D2 = r[:, np.newaxis] + r[np.newaxis, :] - 2 * (X @ X.T)`.
5. Реализуйте **`pair_check(i, j) -> bool`**: сравнивает `D2[i, j]` из `as_matrix()` с прямым подсчётом `((X[i] - X[j]) ** 2).sum()`; возвращает `True`, если значения совпадают с учётом погрешности float (например, `np.isclose`).

**Демонстрация:**

1. `rng = np.random.default_rng(7)`, `X = rng.standard_normal((5, 3))`.
2. Создайте объект вашего класса от `X`, получите `D2 = as_matrix()`.
3. Выведите небольшой фрагмент `D2` (например, верхний левый блок `2×2`).
4. Выведите результат `pair_check(0, 3)` и проверьте, что диагональ `D2` близка к нулю (`np.allclose(D2.diagonal(), 0)` или `print` с округлением).

# Задачи: NumPy — средний уровень (Middle)

**Уровень:** Middle (слегка упрощённый) + одна задача **Middle+**  
**Темы:** индексирование и копии, `np.where`, `np.clip`, сетка `meshgrid`, сборка массивов, `argsort`, нормализация столбцов, норма и **матрица попарных квадратов расстояний** (вещание + `@`)

**Предполагается:** базовые массивы, срезы и векторизация из `TASKS.md`.

## Задача 1. Срезы и «умные» индексы

**Цель:** Почувствовать разницу между срезом (view) и выбором по списку индексов.

1. Создайте `a = np.arange(12).reshape(3, 4)`.
2. Возьмите `b = a[0:2, 1:3]`, поставьте `b[0, 0] = 999`. Убедитесь, что в `a` тоже изменилось значение (это общая память со срезом).
3. Возьмите `c = a[[0, 2], :]` (две строки). Поставьте `c[0, 0] = -100`. Посмотрите на `a[0, 0]` — изменилось ли? (Напишите в комментарии «да» или «нет».)

## Задача 3. `np.clip`

**Цель:** Ограничить значения с обоих концов.

1. `rng = np.random.default_rng(42)`; `v = rng.standard_normal(15)`.
2. Получите `w = np.clip(v, -1.0, 1.0)` — все элементы должны лежать в `[-1, 1]`.
3. (По желанию) Посчитайте, сколько элементов в `v` было **вне** этого интервала до обрезки.

## Задача 4. Сетка `meshgrid`

**Цель:** Две координаты на плоскости, одна формула на всю сетку.

1. `X, Y = np.meshgrid(np.linspace(0, 1, 4), np.linspace(0, 1, 3), indexing="xy")`.
2. `Z = X ** 2 + Y ** 2`.
3. Найдите **минимальное** значение в `Z` и его **плоский** индекс: `np.argmin(Z)`. (Индексы строки/столбца можно не вычислять.)

## Задача 6. Сортировка по оценкам

**Цель:** `argsort` и перестановка второго списка в том же порядке.

1. `scores = np.array([78, 92, 65, 88])`, имена: `["Аня", "Борис", "Вера", "Глеб"]` (в том же порядке).
2. Индексы по убыванию оценок: `idx = scores.argsort()[::-1]`.
3. Выведите имена в порядке от лучшей оценки к худшей: `[names[i] for i in idx]` или индексация массива имён, если сделали его `np.array`.

## Задача 7. Нормализация столбцов (z-score)

**Цель:** Вычитание среднего и деление на std по каждому столбцу.

1. `rng = np.random.default_rng(0)`; `D = rng.standard_normal((30, 3))` — 30 строк, 3 столбца.
2. `mu = D.mean(axis=0)`, `sigma = D.std(axis=0, ddof=0)`.
3. `D2 = (D - mu) / sigma` — вещание: `D` минус вектор длины 3 по столбцам.
4. Проверка: `D2.mean(axis=0)` должно быть близко к нулю, `D2.std(axis=0)` — близко к 1 (используйте `np.round(..., 10)` при выводе, если мешают мелкие ошибки float).

## Задача 8. Расстояние между двумя точками

**Цель:** Норма разности, без матрицы всех пар.

1. `p = np.array([1.0, 2.0])`, `q = np.array([4.0, 6.0])`.
2. Квадрат расстояния: `((p - q) ** 2).sum()` или `np.linalg.norm(p - q) ** 2`.
3. То же для трёх пар точек из матрицы `X = np.array([[0, 0], [1, 0], [0, 2]])`: расстояние между строкой 0 и 1, между 0 и 2, между 1 и 2 (можно три раза подставить разные `p`, `q` — цикл `for` по парам здесь **разрешён**).

## Задача 9 (Middle+). Матрица квадратов расстояний без циклов по парам

**Цель:** Собрать матрицу `D2` размера `P×P`, где `D2[i, j]` — квадрат евклидова расстояния между `i`-й и `j`-й **строками** матрицы данных `X` формы `(P, k)`.

1. Задайте, например, `rng = np.random.default_rng(7)` и `X = rng.standard_normal((5, 3))` — 5 точек в пространстве размерности 3.
2. Вектор квадратов норм строк: `r = (X ** 2).sum(axis=1)` — форма `(P,)`.
3. Используйте вещание и матричное умножение:  
   `D2 = r[:, np.newaxis] + r[np.newaxis, :] - 2 * (X @ X.T)`  
   (это следует из тождества `‖a−b‖² = ‖a‖² + ‖b‖² − 2(a·b)` для строк `a`, `b`).
4. Убедитесь, что диагональ `D2` состоит из нулей (с допуском `np.allclose(D2.diagonal(), 0)` или `np.round`).
5. **Проверка:** для пары индексов `(0, 3)` сравните `D2[0, 3]` с «ручным» значением `((X[0] - X[3]) ** 2).sum()` — должно совпасть с точностью float.

**Замечание:** двойной цикл `for i … for j …` для заполнения `D2` в этой задаче **не использовать** — только формула выше.

# Задачи: Pandas — обработка данных (часть 1)

**Уровень:** Beginner  
**Темы:** `Series`, `DataFrame`, чтение/запись CSV, индексация `loc/iloc`, фильтрация, новые столбцы, `groupby`, `merge/concat`, пропуски `NaN`, базовая визуализация данных

---

## Задача 1. `Series`: создание и свойства

**Цель:** Освоить базовый объект `Series`.

1. Создайте `s = pd.Series([10, 20, 30], name="score")`.
2. Выведите `s.dtype`, `s.name`, `s.index`.
3. Выведите второй элемент двумя способами: по позиции и по метке (задайте индекс, например `["a","b","c"]`).

---

## Задача 2. `DataFrame`: создание, выбор столбцов

**Цель:** Создать таблицу и научиться выбирать столбцы.

1. Создайте `df` с колонками `name`, `age`, `score` на 4–5 строк.
2. Выведите `df.head()` и `df.info()`.
3. Проверьте разницу между `df["age"]` и `df[["age"]]` (тип и вывод).

---

## Задача 3. Индексация: `loc` и `iloc`

**Цель:** Понять разницу выбора по меткам и по позициям.

1. Задайте `df.index = ["s1","s2","s3","s4"]` (или любой набор меток).
2. С помощью `loc` получите значение `score` для строки `"s2"`.
3. С помощью `iloc` получите то же значение через позиционные индексы.
4. Выведите подтаблицу 2×2: первые две строки и первые два столбца через `iloc`.

---

## Задача 4. Фильтрация строк по условию

**Цель:** Отобрать строки по булевому условию.

1. Выведите всех студентов, у которых `score >= 80`.
2. Выведите всех студентов, у которых `age == 19` и `score >= 80`.
3. Отсортируйте результат по `score` по убыванию (`sort_values`).

---

## Задача 5. Новые столбцы и присваивания по условию

**Цель:** Добавить вычисляемые признаки.

1. Добавьте столбец `passed`: `True`, если `score >= 70`, иначе `False`.
2. Добавьте столбец `grade`:
   - `A`, если `score >= 90`
   - `B`, если `80 <= score < 90`
   - `C`, если `score < 80`
3. Сделайте это через `loc` с условиями (без циклов по строкам).

---

## Задача 6. `groupby` + `agg`

**Цель:** Сгруппировать данные и посчитать агрегаты.

1. Создайте таблицу `df` со столбцами `student`, `subject`, `score` (минимум 6–8 строк, чтобы один студент встречался несколько раз).
2. Посчитайте по каждому `student`: `count`, `mean`, `min`, `max` для `score`.
3. (По желанию) Постройте `pivot_table` с индексом `student`, колонками `subject` и значениями `score`.

---

## Задача 7. Объединения таблиц: `merge` и `concat`

**Цель:** Научиться соединять данные.

1. Создайте `left`: `student_id`, `name` (например, id 1..3).
2. Создайте `right`: `student_id`, `group` (например, id 1..2 и ещё один id, которого нет в `left`).
3. Сделайте `merge` с `how="left"` по `student_id`.
4. Создайте две маленькие таблицы одинаковой структуры и объедините их по строкам через `pd.concat(..., ignore_index=True)`.

---

## Задача 8. Пропуски (`NaN`)

**Цель:** Обработка отсутствующих значений.

1. Создайте `df = pd.DataFrame({"name": ["A","B","C"], "score": [10, None, 30]})`.
2. Выведите маску пропусков: `df.isna()`.
3. Получите версию без пропусков: `df.dropna()`.
4. Заполните пропуски:
   - вариантом 1: `0`
   - вариантом 2: средним по столбцу `score`

# Задачи: Data Visualization with Matplotlib and Seaborn

**Уровень:** Beginner  
**Темы:** базовые графики `matplotlib`, работа с осями и подписями, `line/bar/scatter/hist`, стилизация, `seaborn` (`barplot`, `heatmap`)

---

## Задача 1. Первый график: `line plot`

**Цель:** построить простой линейный график.

1. Создайте список дней `1..7` и список продаж (7 значений).
2. Постройте `plt.plot(days, sales)`.
3. Добавьте `title`, подписи осей `xlabel/ylabel`.
4. Включите сетку `plt.grid(True)`.

---

## Задача 2. Линия + маркеры + стиль

**Цель:** научиться настраивать внешний вид графика.

1. Постройте линию продаж по дням.
2. Добавьте маркеры (`marker="o"`), цвет (`color="teal"`), тип линии (`linestyle="--"`).
3. Добавьте легенду `plt.legend()`.
4. Поэкспериментируйте с `figsize=(8, 4)`.

---

## Задача 3. Столбчатая диаграмма: `bar`

**Цель:** визуализировать агрегаты по категориям.

1. Создайте категории (`Math`, `CS`, `Physics`) и средние баллы.
2. Постройте `plt.bar(...)`.
3. Добавьте ограничение оси Y: `plt.ylim(0, 100)`.
4. Подпишите значения столбцов (по желанию).

## Задача 4. `scatter plot`

**Цель:** увидеть связь между двумя числовыми признаками.

1. Создайте пары значений: `hours_studied` и `score`.
2. Постройте `plt.scatter(...)`.
3. Добавьте заголовок и подписи осей.
4. Сделайте краткий вывод: есть ли положительная зависимость.

## Задача 5. Гистограмма: `hist`

**Цель:** показать распределение значений.

1. Сгенерируйте/задайте список из 20–30 оценок.
2. Постройте гистограмму `plt.hist(scores, bins=5)` (или больше бинов).
3. Добавьте подписи и заголовок.
4. Сравните 2 варианта бинов (например, 5 и 10).

## Задача 7. Seaborn: `heatmap` корреляций

**Цель:** визуализировать корреляционную матрицу.

1. Создайте таблицу с 4–6 числовыми колонками.
2. Посчитайте `corr = df.corr(numeric_only=True)`.
3. Постройте `sns.heatmap(corr, annot=True, cmap="Blues", vmin=-1, vmax=1)`.
4. Укажите, какие признаки коррелируют сильнее всего.
